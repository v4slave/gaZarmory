# Матрица прав

| Операция | ГЛ | Микро-ГЛ | Разработчик | PL | Участник |
|---|:---:|:---:|:---:|:---:|:---:|
| Просмотр состава, активностей, казны и аукционов | ✓ | ✓ | ✓ | ✓ | ✓ |
| Просмотр собственной выплаты и ставка | ✓ | ✓ | ✓ | ✓ | ✓ |
| Игроки, активности, посещаемость и лут | ✓ | ✓ | ✓ | — | — |
| Создание и переименование конст-пати | ✓ | ✓ | ✓ | — | — |
| Управление составом своей конст-пати | ✓ | ✓ | ✓ | ✓ | — |
| Ручные операции с золотом | ✓ | — | ✓ | — | — |
| Создание аукциона | ✓ | — | ✓ | — | — |
| Продажа и выдача предмета из казны | ✓ | — | ✓ | — | — |
| Создание нахрюка | ✓ | — | ✓ | — | — |
| Управление существующими аукционами и выплатами | ✓ | — | ✓ | — | — |
| Подтверждение заявок, админка и audit log | ✓ | — | ✓ | — | — |
| Назначение обычных ролей | ✓ | — | ✓ | — | — |
| Передача единственной роли ГЛ | ✓ | — | — | — | — |
| Назначение роли Разработчик через админку | — | — | — | — | — |

Любая операция требует authenticated session и привязанного персонажа, кроме создания заявки на привязку. Проверки выполняются на backend; ограничения интерфейса лишь дублируют серверную политику.

Микро-ГЛ управляет составом, конст-пати и проведением активностей, но не имеет доступа к админке; в казне, нахрюке и аукционах действует как обычный участник. ГЛ в системе только один: действующий ГЛ передаёт роль другому пользователю с подтверждением, после чего роль автоматически снимается с прежнего владельца. Роль Разработчик через админку не назначается. PL не может переименовать или удалить конст-пати и управляет только перемещением игроков между своей группой и одиночками.
